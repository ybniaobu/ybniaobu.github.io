> 本想通过书籍来学习 C++ 的，但是粗略看了《C++ Primer Plus》、 C++ 之父 Bjarne Stroustrup 的《C++ 程序设计语言》（The C++ Programming Language）以及《C++ 之旅》（A Tour of C++）都不是很满意，要么是废话连篇，要么是结构太乱，非常不适合初学者学习。我最终决定还是按照自己的理解的结构顺序来对 C++ 的语法进行一定的梳理，内容上主要参考了[菜鸟教程的 C++ 教程](https://www.runoob.com/cplusplus/cpp-tutorial.html) 、《C++ Primer》（建议初学者看这本书）、上述书籍以及 AI。  
>   
> 由于是基础笔记，对一些中级或高级内容只做出简单的介绍，更深入的学习建议和实践相结合。另外，本笔记主要基于 C++ 11 标准的，但是会补充一些后续标准的内容。普遍认为<u>现代 C++</u> 始于 C++ 11 及之后的版本。
